Material Symbols Rounded glyph — the only icon source in K.Y.S; use for every UI icon.
```jsx
<Icon name="content_copy" size={20} />
<Icon name="star" fill color="var(--kys-favorite)" />
```
- `fill` for active/selected states (favorites, filled category glyphs).
- Sizes: 18 in chips/buttons, 20 in icon buttons, 22 default.
