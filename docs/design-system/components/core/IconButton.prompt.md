Icon-only button for copy, reveal, favorite, back, import/export and window actions.
```jsx
<IconButton icon="content_copy" title="Copy password" />
<IconButton icon="arrow_back" variant="tonal" shape="square" size={48} title="Back" />
<IconButton icon="star" fill color="var(--kys-favorite)" title="Unfavorite" />
```
- `square` + `tonal` matches the header utility buttons (back, import, export).
