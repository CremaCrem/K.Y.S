Pill-shaped action button; `primary` (solid orange) for the single main action per view, others for secondary actions.
```jsx
<Button icon="add" size="lg">Add password</Button>
<Button variant="outline">Cancel</Button>
<Button variant="danger" icon="delete">Delete</Button>
```
- `xl` + `fullWidth` for form submit (e.g. "Add Password").
- `tonal` for Generate / secondary emphasis; `ghost` for inline text actions ("+ Notes (optional)").
