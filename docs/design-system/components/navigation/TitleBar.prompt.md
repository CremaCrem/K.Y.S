Solid orange desktop title bar — the strongest brand moment in the app. One per window, at the very top.
```jsx
<TitleBar onLock={lock} onToggleTheme={toggle} />
```
- In the app it's 32px tall. Window controls follow the OS: native macOS traffic lights on the left, Windows caption buttons (minimize, maximize/restore, close) on the right. The mock's 52px bar and fixed Windows buttons are for previews only.
